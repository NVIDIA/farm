# Cloud and Kubernetes Deployment

Farm can be deployed to most Cloud Service Providers (CSP) including OCI, GCP, Azure, EKS, AKS, OKE, in addition to generic Kubernetes (K8s).

The following guides describe configuring and deploying Farm to various cloud providers. The intended audience for this document is experienced systems administrators familiar with Kubernetes, CSP specific Kubernetes offerings, and the deployment of [Helm](https://helm.sh/) charts.

For other CSP deployments the *kubernetes deployment guide* may be used in combination with the above guides which should provide sufficient detail to perform the installation on other platforms of your choice.
